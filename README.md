# Pinz Grill — concept redesign

Static concept redesign of [pinzgrill.com](https://www.pinzgrill.com) (Columbia, SC) in the layout pattern of chipotle.com, using Pinz Grill's own logo, photos, menu and prices. Prepared as a sales pitch; not the live site.

- `index.html`, `menu.html`, `catering.html` — the concept (built from `_*.tpl` + `_*.body` by `python3 build.py`)
- `compare.html` — before/after pitch page (desktop + phone screenshots)
- `styles.css` — the only stylesheet
- `assets/` — logo and photos pulled from the current site, recropped

All menu items, prices, hours, phone, address and the ChowNow ordering link are as published on pinzgrill.com on 2026-09-05.
